SoilCF: Deep Neural Network-Based Prediction of Circular failure in Soil Slopes

This repository provides the source code, trained DNN models, and the scalers for predicting the Factor of Safety (FoS) and average shear stress along the critical slip surface, and calculating the average shear strength and average base normal stress (both along the critical slip surface) for circular failure in soil slopes. A standalone Python-based GUI application (SoilCF) is included for practical engineering use without requiring Python installation.

Authors: Avishek Dutta, Kripamoy Sarkar
